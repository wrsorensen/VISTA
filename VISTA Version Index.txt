VISTA Version Index
Vacation Inventory, Service & Task Administration

Purpose
Use this index as the GitHub archive control center. Version file links open the hosted snapshots, so old VISTA HTML files do not need to be kept locally. Download from the HTML index grabs this full TXT notes file. v0.0.7 was rolled into v0.0.8 and was not saved as a separate file.
