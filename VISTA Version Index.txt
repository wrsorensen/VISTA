Future Updates

- Upload validation: reject files that do not match the required VISTA/Breezeway format.
- Backend import: accept the same rows and columns every upload until a smarter importer is intentionally built.
- Future AI import: add assisted column mapping for alternate Breezeway/report downloads, with preview and confirmation before import.
- Security: replace demo PIN with Google/multi-user login and admin-only upload rights.
- Task transparency: add a script function to check off completed tasks from the app until a new spreadsheet is uploaded.
- Data path: move from embedded demo data to Google Apps Script/GitHub-backed data when ready.
- Mobile access: test through the live GitHub Pages URL, not a local Windows file path.
